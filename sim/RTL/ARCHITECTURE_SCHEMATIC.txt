================================================================================
                      SIGNAL FLOW - INSTRUCTION FETCH
================================================================================

1. Core outputs virtual instruction address (inst_vaddr)
2. MMU receives virtual address
3. MMU checks TLB for translation
4. If TLB hit:
   - Get physical address from TLB
   - Go to step 5
5. If TLB miss:
   - Perform page table walk
   - Get PTE from page table
   - Update TLB with new entry
   - Go to step 5
6. MMU outputs physical address (inst_paddr)
7. Instruction Memory receives physical address
8. SRAM returns instruction data
9. Core receives instruction data (inst_data)
10. Decode and execute


================================================================================
                      SIGNAL FLOW - DATA ACCESS
================================================================================

Similar to instruction fetch:
1. Core outputs virtual data address (data_vaddr)
2. Core outputs write data (data_wdata) if write
3. MMU performs address translation (TLB or page table walk)
4. MMU outputs physical address (data_paddr)
5. Data Memory performs read/write at physical address
6. Memory returns data (data_rdata) if read
7. Core receives result


================================================================================
                   SIGNAL FLOW - CSR OPERATIONS
================================================================================

1. Core executes CSR instruction (CSRRW, CSRRS, CSRRC)
2. Core outputs CSR signals:
   - csr_valid = 1
   - csr_addr = CSR address (12-bit)
   - csr_op = operation type
   - csr_wdata = write data
3. CSR Unit receives signals
4. CSR Unit performs operation:
   - Read from CSR register
   - Perform operation (W/S/C)
   - Write result if needed
5. CSR Unit returns csr_rdata
6. Core writes result to rd register


================================================================================
                   SIGNAL FLOW - EXCEPTION HANDLING
================================================================================

1. Exception occurs (synchronous or asynchronous)
2. Exception source signals:
   - exception_valid = 1
   - exception_code = exception type
   - exception_badaddr = fault address (if applicable)
3. Exception Handler receives signals
4. Exception Handler prioritizes exceptions
5. CSR Unit updated with:
   - MEPC = PC when exception occurred
   - MCAUSE = exception code
   - MTVAL = bad address
6. Exception Handler outputs:
   - trap_taken = 1
   - trap_handler_addr = address of trap handler (from MTVEC)
7. Core receives trap info
8. Core jumps to trap handler

                   MEMORY MAP & ADDRESS DECODING
================================================================================

Virtual Address Space (32-bit):
┌──────────────────────────────────────┐
│ 0x8000_0000 - 0x8000_FFFF            │ Peripherals (AXI4-Lite)
│ 0x0001_0000 - 0x0001_3FFF            │ Data Memory (16KB)
│ 0x0000_0000 - 0x0000_3FFF            │ Instruction Memory (16KB)
└──────────────────────────────────────┘

Physical Address Space (32-bit):
┌──────────────────────────────────────┐
│ [Same as virtual in bare mode]        │ or [Translated via page table]
└──────────────────────────────────────┘

Page Table Format (Sv32):
┌─────────────────────────────────────┐
│ [31:20] Reserved                    │
│ [19:0]  Physical Page Number (PPN)  │
│ [11:10] Reserved                    │
│ [9]     Dirty Flag (D)               │
│ [8]     Accessed Flag (A)            │
│ [7]     Global Flag (G)              │
│ [6]     User Mode (U)                │
│ [5]     Execute Permission (X)       │
│ [4]     Write Permission (W)         │
│ [3]     Read Permission (R)          │
│ [2]     Reserved                     │
│ [1]     Reserved                     │
│ [0]     Valid (V)                    │
└─────────────────────────────────────┘

                       DATA PATH WIDTHS
================================================================================

Physical Address:       32 bits (inst_paddr, data_paddr)
Instruction:            32 bits (inst_data)
Data (Load/Store):      32 bits (data_wdata, data_rdata)
Byte Enable:            4 bits (data_byte_en)
Register:               32 bits (all 32 registers)
CSR Address:            12 bits (csr_addr)
CSR Data:               32 bits (csr_wdata, csr_rdata)
Exception Code:         4 bits (exception_code)
CSR Operation:          2 bits (csr_op: RW/S/C)
