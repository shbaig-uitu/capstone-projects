================================================================================
                        WAVEFORM VIEWING GUIDE
================================================================================

OPEN WAVEFORM:
  Command: gtkwave riscv_soc.vcd

NAVIGATE IN GTKWAVE:
  Left Panel:   Signal hierarchy (expand to see signals)
  Right Panel:  Waveform display
  Bottom:       Timeline and zoom controls

ADD SIGNALS:
  Method 1: Drag from left panel to right
  Method 2: Right-click signal name → Add to waveform

ZOOM IN/OUT:
  Zoom in:  Press + or scroll up
  Zoom out: Press - or scroll down
  Fit:      Press Shift+F

KEY SIGNALS TO MONITOR:
  tb_riscv_soc.clk              - Should see 100 MHz square wave
  tb_riscv_soc.rst_n            - Should see pulse at start
  tb_riscv_soc.gpio_in/out      - Should match (both 0xAA)
  tb_riscv_soc.uart_rx/tx       - Should match (both 1)

EXPORT WAVEFORMS:
  File → Export → PNG/PDF (to save as image)
  File → Print (to print waveforms)
  File → Save As (to save current view)
