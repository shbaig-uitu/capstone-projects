CORE UVM COMPONENTS BREAKDOWN
================================================================================

1. INTERFACE (uvm_riscv_if.sv) - 100 lines
   - Clock and reset management
   - UART interface (uart_rx, uart_tx)
   - GPIO interface (gpio_in[7:0], gpio_out[7:0])
   - AXI4-Lite debug interface (14 signals)
   - External interrupt input
   - Modports for driver, monitor, testbench access

2. TRANSACTION CLASSES (uvm_riscv_transaction.sv) - 150 lines
   - gpio_transaction: input, output, expected value
   - uart_transaction: RX, TX, expected echo
   - axi_transaction: read/write, address, data, response
   - interrupt_transaction: interrupt signal, delay
   - clock_transaction: cycle count, reset control
   All with copy(), convert2string(), randomization support

3. SEQUENCERS (uvm_riscv_sequencer.sv) - 50 lines
   - gpio_sequencer: generates GPIO stimuli
   - uart_sequencer: generates UART stimuli
   - axi_sequencer: generates AXI transactions
   - interrupt_sequencer: generates interrupts

4. DRIVERS (uvm_riscv_driver.sv) - 200 lines
   - gpio_driver: applies GPIO inputs to DUT
   - uart_driver: applies UART RX to DUT
   - axi_driver: handles AXI write/read transactions
   - interrupt_driver: generates interrupt pulses

5. MONITORS (uvm_riscv_monitor.sv) - 250 lines
   - gpio_monitor: observes GPIO transactions
   - uart_monitor: captures UART activity
   - axi_monitor: captures AXI transactions
   - interrupt_monitor: observes interrupt events

6. AGENTS (uvm_riscv_agent.sv) - 150 lines
   - gpio_agent: combines GPIO sequencer, driver, monitor
   - uart_agent: combines UART sequencer, driver, monitor
   - axi_agent: combines AXI sequencer, driver, monitor
   - interrupt_agent: combines interrupt sequencer, driver, monitor

7. SCOREBOARDS (uvm_riscv_scoreboard.sv) - 300 lines
   - gpio_scoreboard: verifies GPIO pass-through (IN == OUT)
   - uart_scoreboard: verifies UART echo (RX == TX)
   - axi_scoreboard: verifies AXI responses (RESP == OKAY)
   - top_scoreboard: aggregates all results and generates final report

8. COVERAGE (uvm_riscv_coverage.sv) - 200 lines
   - gpio_coverage: tracks GPIO value patterns
   - uart_coverage: tracks UART state transitions
   - axi_coverage: tracks AXI address/data ranges

9. SEQUENCES (uvm_riscv_sequences.sv) - 250 lines
   - gpio_passthrough_sequence: 40 GPIO transactions
   - uart_echo_sequence: 20 UART transactions
   - axi_write_sequence: 25 AXI writes
   - axi_read_sequence: 25 AXI reads
   - interrupt_sequence: interrupt pulse generation
   - reset_sequence: reset observation

10. ENVIRONMENT (uvm_riscv_env.sv) - 100 lines
    - Instantiates all agents
    - Connects monitors to scoreboards
    - Manages coverage collection

11. TEST CASES (uvm_riscv_test.sv) - 300 lines
    - riscv_uvm_base_test: base class with DUT instantiation
    - gpio_passthrough_test: GPIO functionality
    - uart_echo_test: UART loopback
    - axi_write_test: AXI write operations
    - axi_read_test: AXI read operations
    - interrupt_test: interrupt generation
    - riscv_regression_test: all tests combined

12. PACKAGE (uvm_pkg.sv) - 100 lines
    - Includes all components in proper order
    - Type definitions and enumerations
    - Parameters and constants

SUPPORT AND DEBUGGING
================================================================================

ISSUE: Tests won't compile
FIX: Verify ../rtl/ directory contains all RTL files
     Check RTL file paths in compile script

ISSUE: Virtual interface not found
FIX: Check tb_riscv_uvm.sv line 95
     Verify uvm_config_db #(virtual riscv_soc_if)::set(...) 

ISSUE: Tests fail unexpectedly
FIX: Check uvm_simulation.log for "ERROR" or "FAIL" messages
     Open reports/riscv_uvm.vcd in GTKWave
     Verify DUT instantiation and signal connections

ISSUE: Simulation timeout
FIX: Increase #10000000 in tb_riscv_uvm.sv
     Check for infinite loops in test sequences
     Verify clock generation

ISSUE: No waveform generated
FIX: Check simulation completed successfully
     Verify $dumpfile in tb_riscv_uvm.sv enabled
     Check disk space available
